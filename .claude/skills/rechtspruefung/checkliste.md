# Checkliste Rechtsprüfung (Deutschland)

| Bereich | Prüfen |
|---|---|
| Impressum (§ 5 DDG) | Von jeder Seite mit einem Klick erreichbar. Name, ladungsfähige Anschrift, Kontakt (E-Mail und ein zweiter schneller Weg), bei Vereinen Vertretungsberechtigte und Registereintrag, ggf. USt-IdNr. |
| Verantwortlich für Inhalte (§ 18 MStV) | Bei journalistisch-redaktionellen Inhalten (Blog, News) Name und Anschrift |
| Datenschutzerklärung (Art. 13 DSGVO) | Verantwortlicher, Hosting, Server-Logs, Kontaktformular, Rechte der Betroffenen, Beschwerderecht, jede eingebundene Fremdleistung |
| Verbindungen zu Dritten | Keine Fonts, Skripte, Karten, Videos von fremden Servern ohne Einwilligung. Lokal ausliefern oder Zwei-Klick-Lösung |
| Cookies und Speicher (§ 25 TDDDG) | Nur technisch notwendige ohne Einwilligung. Sonst Banner mit gleichwertigem Ablehnen |
| Formulare | Nur nötige Felder, Hinweis auf Datenschutz, Übertragung per HTTPS, Spam-Schutz ohne Google reCAPTCHA |
| Bildrechte | Für jedes Bild: Quelle, Lizenz, Urheber-Nennung wo verlangt. Stockfotos mit Lizenznachweis |
| Personen auf Fotos | Einwilligung der Abgebildeten, bei Kindern der Eltern. Veröffentlichte Namenslisten nur mit Einwilligung |
| Barrierefreiheit | WCAG 2.1 AA. Pflicht nach BFSG für bestimmte Angebote an Verbraucher, sonst Empfehlung. Prüfen ob Pflicht |
| Verlinkte Dokumente | PDFs (Formulare, Flyer) mit eigenem Datenschutzhinweis, wenn sie Daten erfragen |
| Externe Links | Funktionieren, keine Weiterleitung auf fremde Inhalte ohne Kennzeichnung |
| Ehrenamt, Verein | Bei Vereinen: wer Vorstand ist, Satzung bei Bedarf, Spendenhinweise korrekt |
