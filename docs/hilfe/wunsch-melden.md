Jeder Wunsch und jeder Fehler wird ein **Issue**, also ein Eintrag in der gemeinsamen Liste auf GitHub.
So geht nichts in Mails verloren und jeder sieht, was gerade passiert.

## So geht es

1. Auf GitHub im Projekt den Reiter **Issues** öffnen, **New issue** klicken.
2. Die Vorlage **Änderungswunsch** oder **Fehler** wählen.
3. Ausfüllen, Screenshots einfach hineinziehen, absenden.

Ohne GitHub-Konto: eine Mail an den Ansprechpartner Technik genügt. Er überträgt sie als Issue.

## Was danach passiert

| Schritt | Woran man es sieht |
|---|---|
| Wunsch wird gesichtet und beschrieben | Label `bereit` oder eine Rückfrage im Issue |
| Umsetzung | Label `in-arbeit` |
| Prüfen auf der Testseite | Label `in-review`, Link zur Testseite im Pull Request |
| Liegt bereit für das nächste Release | Label `fertig` |
| Online | Issue wird geschlossen |
