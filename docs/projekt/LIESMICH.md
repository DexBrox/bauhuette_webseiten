# Projektunterlagen

Die Dateien hier entstehen im Ablauf, nicht von Hand:

| Datei | Phase | Skill |
|---|---|---|
| `anf.md` | 1 Interview | `/interview` |
| `prd.md` | 2 PRD | `/prd` |
| `issues.md` | 4 Zerlegung | `/zerlegen` (schreibt `parlier issues anlegen`) |

`backlog-redaktion.json` ist ein fertiger Zerlegungs-Entwurf für den Baustein Redaktion. Anlegen mit
`python3 -m parlier issues anlegen docs/projekt/backlog-redaktion.json --trocken` (ohne `--trocken` echt).
