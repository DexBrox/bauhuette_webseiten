# Glossar

Gleiche Wörter für gleiche Dinge in Gespräch, Doku und Code. Das Interview ergänzt die Fachbegriffe des Projekts.

## Bauhütte

| Begriff | Bedeutung |
|---|---|
| Bauhütte | dieser Workflow: Phasen, Rollen, Regeln |
| Parlier | die Hauptsitzung von Claude, die verteilt und prüft; auch das Python-Werkzeug |
| Hüttenordnung | `CLAUDE.md` |
| Freigabe | Vale bestätigt ausdrücklich, im Frontmatter steht `status: freigegeben` |
| Slice | ein Issue als dünner Durchstich durch alle Schichten, nach dem man etwas sehen kann |
| AFK | Agent setzt allein um, Label `bereit` |
| HITL | braucht Vale, Label `mensch` |
| Ralph | Schleife, die Issues AFK abarbeitet |
| Gegenrede | Ergebnis des Advocatus Diaboli |
| ADR | Architekturentscheidung mit Alternativen, `docs/technik/adr/` |
| Redaktion | Oberfläche, in der Pflegende Inhalte ohne Git ändern |
| Testseite | Vorschau eines Zweigs auf GitHub Pages |
